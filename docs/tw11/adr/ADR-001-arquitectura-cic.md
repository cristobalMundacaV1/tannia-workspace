# ADR-001 — Arquitectura del Construction Intelligence Core
**Estado:** adoptada (G0). **Contexto:** docs/tw11/02, 11 (CIC-01). **Decisión:** el CIC es un servicio de dominio determinista en `src/cic/` + `src/geo/`, expuesto por herramientas `tannia_cic_*` **solo con `TANNIA_CIC=on`**. Claude propone interpretaciones y planes; el backend valida y calcula. No hay clasificador léxico en el camino crítico; la disciplina es informativa. Patrón *strangler*: las 72 herramientas de rc3 no cambian (snapshot de esquemas). **Consecuencias:** con el flag apagado, comportamiento idéntico a rc3 (probado); nuevas capacidades se prueban con flag encendido. **Alternativas descartadas:** reescribir el enrutador de autonomía (riesgo de regresión); un generador por tipo de proyecto (no generaliza).
