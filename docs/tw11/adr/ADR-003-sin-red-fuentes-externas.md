# ADR-003 — El servidor no tiene red; fuentes externas por candidatura y aprobación humana
**Estado:** adoptada (G3). El servidor MCP no accede a Internet. La investigación externa la hace Claude con herramientas que la usuaria autorizó en Claude Desktop; lo hallado entra como **fuente candidata** (extracto + URL + fecha) y solo una **persona** la aprueba: por elicitación del cliente o por un archivo creado fuera de la conversación con un código que Claude no puede obtener por las herramientas. Ningún parámetro booleano puede aprobar. Estados separados: registrada ≠ aprobada ≠ contenido disponible ≠ extracto comprobado ≠ cita verificable. Limitaciones declaradas: el servidor no verifica que la web diga lo declarado ni impide que Claude envíe datos a una búsqueda externa.
